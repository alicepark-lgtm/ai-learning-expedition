📈 회귀 (Regression)

지도학습

연속적인 수치를 예측. 입력값과 결괏값의 관계를 함수로 표현.

  • 학습 시간 → 성적 예측
  • 기온 변화 예측
  • 중고차 가격 예측

🗂️ 분류 (Classification)

지도학습

데이터가 어느 범주(클래스)에 속하는지 판단.

  • 스팸 메일 분류
  • 손 글씨 숫자 판별
  • 암 양성/음성 분류

🔵 군집화 (Clustering)

비지도학습

정답 없이 유사한 특징의 데이터끼리 그룹화.

  • 고객 세분화 마케팅
  • 비슷한 사진 모으기
  • 화장품 브랜드 군집화

🔗 연관 규칙 (Association)

비지도학습

데이터 항목들 간의 연관성을 탐색하여 규칙 발견.

  • 도서 추천 시스템
  • 음악 추천 서비스
  • 장바구니 분석
🔑 핵심 용어
훈련 데이터 (Training Data) — 모델 학습에 사용하는 데이터. 정답(레이블)이 포함됨.

📈 회귀(Regression) 모델이란?

회귀는 연속적인 수치형 데이터를 예측하는 지도학습 방법입니다. 입력값과 결괏값의 관계를 잘 나타내는 함수를 만들고, 새로운 값이 입력되면 이 함수를 이용하여 예측합니다.

📉 회귀 모델 평가

회귀 모델은 예측값이 실제값에 얼마나 가까운지를 수치로 평가합니다. 대표적인 평가 지표 3가지를 알아봅니다.

MAE 평균 절대 오차 (Mean Absolute Error)

예측값과 실제값 차이의 절댓값을 평균 낸 값입니다. 오차의 크기를 직관적으로 파악할 수 있습니다.

MAE = (|예측값₁ - 실제값₁| + |예측값₂ - 실제값₂| + …) ÷ n
예시) 실제: 70점, 예측: 74점 → 오차 = |74-70| = 4
실제: 85점, 예측: 81점 → 오차 = |81-85| = 4
MAE = (4 + 4) ÷ 2 = 4.0점
MSE 평균 제곱 오차 (Mean Squared Error)

오차를 제곱하여 평균 낸 값입니다. 큰 오차에 더 민감하게 반응하여 이상치의 영향을 크게 반영합니다.

MSE = ((예측값₁ - 실제값₁)² + (예측값₂ - 실제값₂)² + …) ÷ n
예시) 오차가 4, 4일 때 → MSE = (4² + 4²) ÷ 2 = 16.0
오차가 1, 7일 때 → MSE = (1² + 7²) ÷ 2 = 25.0 ← 큰 오차(7)에 민감!
R² 결정계수 (R-squared)

모델이 데이터의 변동을 얼마나 잘 설명하는지 나타내는 값입니다. 1에 가까울수록 모델 성능이 좋습니다.

😊
R² ≈ 1.0
매우 좋은 모델
😐
R² ≈ 0.5
개선이 필요한 모델
😟
R² ≈ 0
예측력이 낮은 모델

🗂️ 분류(Classification) 모델이란?

입력 데이터가 미리 정의된 둘 이상의 범주(클래스) 중 어디에 해당하는지 판단합니다. 주어진 데이터로 클래스를 구분하는 경계를 학습합니다.

암 양성/음성 판별 손 글씨 숫자 인식 스팸 메일 분류 진짜/위조 지폐 판별
🌲 (1) 결정트리 (Decision Tree)

트리 구조 기반의 알고리즘. 루트에서부터 각 분기마다 특징에 대한 분류 기준을 만들어 데이터를 분류합니다. 분류 문제와 회귀 문제 모두 적용 가능합니다.

결정트리 알고리즘

  1. 1
    데이터를 가장 잘 분류할 수 있는 특징을 선택한다.
  2. 2
    선택한 특징의 기준값에 따라 크고 작음을 비교하여 하위 그룹으로 나눈다.
  3. 3
    하위 그룹에서 다시 기준값을 정하고 나누는 과정을 반복한다.

📉 (2) 로지스틱 회귀 (Logistic Regression)

데이터가 어떤 클래스에 속할 확률을 0~1 사이의 값으로 예측하고, 확률이 더 높은 클래스로 분류합니다. 주로 0.5를 기준으로 분류합니다.

🎯 (3) k-최근접 이웃 (kNN)

새로운 데이터가 들어왔을 때, 가장 가까운 k개 이웃 데이터의 클래스를 확인하고, 더 많은 수가 속하는 클래스로 분류합니다.

kNN 알고리즘

  1. 1
    기존 데이터와 예측할 데이터 사이의 거리를 각각 계산한다.
  2. 2
    거리가 가까운 순서대로 k개의 이웃을 찾는다.
  3. 3
    k개의 이웃 중 더 많은 수의 이웃이 속한 클래스로 분류한다.

k 값에 따른 분류 결과 예시

빨간 원 = 진짜 지폐 파란 원 = 위조지폐 ⭐ 노란 별 = 새 데이터
k = 1
가장 가까운 1개 = 파란 원
→ 위조지폐로 분류
k = 5
가까운 5개 중 빨간 원 더 많음
→ 진짜 지폐로 분류
거리 계산 방법
P1(1,1), P2(5,4) 일 때:
• 유클리디안 거리 = √((5-1)²+(4-1)²) = 5
• 맨하튼 거리 = |5-1|+|4-1| = 7
※ 거리 기반 알고리즘(kNN, 로지스틱 회귀)은 모델 학습 전 데이터 정규화 필요

Recall = TP / (TP + FN)
💡 정밀도 vs 재현율
암 진단처럼 놓치면 안 되는 경우는 재현율을 높이는 것이 중요합니다.
스팸 메일처럼 오분류가 불편한 경우는 정밀도를 높이는 것이 중요합니다.
🔵 군집화(Clustering)란?

정답이 없는 데이터의 특징을 분석하여 서로 비슷한 특징을 가진 데이터끼리 그룹화하는 비지도학습입니다. 같은 군집 안의 데이터는 유사하고, 다른 군집과는 차이가 크도록 합니다.

💡 분류 vs 군집화 — 분류는 대상의 종류를 판별하는 데 목적이 있고, 군집화는 군집 결과로 얻은 정보를 해석하고 활용하는 데 목적이 있습니다. 군집화에서 형성된 군집이 맞거나 틀렸다고 할 수 없습니다.
시장 세분화 마케팅 비슷한 사진 모아 관리 화장품 브랜드 분석 고객 성향 그룹화
📌 k-평균 군집화 (k-Means Clustering)

주어진 데이터를 k개의 군집으로 묶는 비지도학습 방법. 중심점(centroid)을 반복적으로 이동하며 군집을 업데이트합니다.

k-평균 알고리즘

  1. 1
    군집 개수 k를 정하고, 임의의 위치에 k개의 초기 중심점을 설정한다.
  2. 2
    각 데이터를 가장 가까운 중심점의 군집에 할당한다.
  3. 3
    군집의 중심점을 군집에 속한 데이터들의 평균 위치로 변경한다.
  4. 4
    중심점이 더 이상 변하지 않을 때까지 2~3을 반복한다.

셔츠 크기 군집화 예시 (k=3)

키와 허리둘레 데이터를 이용해 S, M, L 3개 그룹으로 분류

🔵 군집 1 (S) — 키 작고 허리 작음
🟢 군집 2 (M) — 중간 키·허리
🟠 군집 3 (L) — 키 크고 허리 큼
💡 군집의 개수 k에 따라 성능이 달라질 수 있으므로 적절한 k를 정하는 것이 중요합니다!
