🔹 추상화(Abstraction)란?

›

추상화는 문제 해결에 불필요한 세부 사항을 제거하고 핵심적인 내용만 추려 표현하는 것입니다.

예) 지하철 노선도는 실제 거리와 지형을 무시하고 역 이름·환승 정보만 남긴 추상화입니다.

💡 추상화 → 알고리즘 설계 → 프로그래밍 순서로 문제를 해결합니다.
절차 추상화

어떻게(How) 계산하는지 숨기고 무엇(What)을 하는지만 표현. 함수가 대표적 예시.

데이터 추상화

복잡한 데이터를 단순하게 표현. 리스트, 변수 등이 대표적 예시.

🔹 의사코드(Pseudocode) 예시

›

의사코드는 특정 프로그래밍 언어 문법 없이 알고리즘 논리를 표현하는 방법입니다.

예시: 1부터 n까지의 합 구하기
// 의사코드
시작
  n ← 입력받기
  합계 ← 0
  i ← 1
  반복 (i ≤ n):
    합계 ← 합계 + i
    i ← i + 1
  출력 합계
종료
# 파이썬 코드로 변환
n = int(input())
total = 0
for i in range(1, n + 1):
    total += i
print(total)
💡 의사코드는 실제 코드 작성 전 논리 흐름을 설계할 때 사용합니다. 언어마다 문법이 달라도 의사코드는 공통적으로 이해할 수 있습니다.

🔹 버블 정렬 (Bubble Sort) + 시뮬레이션

›

인접한 두 원소를 비교해 순서가 잘못되면 교환하는 방식. 가장 큰 값이 매 회전마다 맨 뒤로 이동합니다.

  • n개 데이터 → 최대 n-1회 반복 (패스)
  • 시간 복잡도: O(n²)
버블 정렬 단계별 시뮬레이션
기본
비교 중
교환
정렬 완료
0 / 0 단계
▶ [초기화] 버튼을 눌러 시뮬레이션을 시작하세요.
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):        # 전체 패스 횟수
        for j in range(n - 1 - i):  # 이미 정렬된 뒤는 제외
            if arr[j] > arr[j + 1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

🔹 선택 정렬 (Selection Sort) + 시뮬레이션

›

전체에서 가장 작은 값을 찾아 맨 앞으로 이동시키는 방식을 반복합니다.

  • 매 회전마다 최솟값 인덱스를 기억했다가 교환
  • 시간 복잡도: O(n²)
선택 정렬 단계별 시뮬레이션
기본
비교 중
현재 최솟값
정렬 완료
0 / 0 단계
▶ [초기화] 버튼을 눌러 시뮬레이션을 시작하세요.
def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

🔹 순차 탐색 (Sequential Search) + 시뮬레이션

›

데이터를 처음부터 끝까지 순서대로 하나씩 비교하며 찾는 방식.

  • 시간 복잡도: O(n)

비교 중
발견!
통과

▶ 탐색할 값을 입력하고 [초기화] 버튼을 눌러 시작하세요.
def sequential_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i       # 찾은 위치(인덱스) 반환
    return -1           # 없으면 -1 반환

🔹 이진 탐색 (Binary Search) + 시뮬레이션

›

정렬된 데이터에서 중간값과 비교하며 탐색 범위를 절반씩 줄여가는 방식.

  • 반드시 정렬된 데이터에서만 사용 가능
  • 시간 복잡도: O(log n) — 순차탐색보다 훨씬 빠름
이진 탐색 단계별 시뮬레이션
L left
M mid
R right
발견!
탐색 범위 제외
0 / 0 단계
▶ 탐색할 값을 입력하고 [초기화] 버튼을 눌러 시작하세요.
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
⚠️ 이진 탐색은 반드시 정렬된 데이터에서만 사용 가능합니다!

🔹 복합 대입 연산자

변수에 연산 후 결과를 다시 대입하는 축약 형태입니다.

연산자 이름설명예시동일한 표현
+=숫자 덧셈 후 대입a += 3a = a + 3
-=숫자 뺄셈 후 대입a -= 3a = a - 3
*=숫자 곱셈 후 대입a *= 3a = a * 3

a = 10

print(a)  # 36

🔹 if / elif / else 구조

›

📌 기본 구조

if 조건 :
    실행할 코드 1
    실행할 코드 2

elif 조건 :
    실행할 코드 3
    실행할 코드 4

else :
    실행할 코드 5
📌 작동 방식
  • if 조건이 참 → 코드 1, 2 실행
  • if 조건이 거짓 → elif 조건 검사
  • elif 조건이 참 → 코드 3, 4 실행
  • if, elif 모두 거짓 → else 코드 5 실행
💡 elif는 원하는 만큼 여러 개 추가 가능. else는 생략 가능하지만 작성 권장.
⚠️ 파이썬은 들여쓰기(4칸)로 블록을 구분합니다. if-elif-else는 위에서부터 순서대로 검사해 처음 참인 블록 하나만 실행합니다.

🔹 while 반복문 — 작동 원리

›

조건식이 참인 동안 내부 코드를 반복 실행합니다.

# 초기식
i = 0
# 조건식
while i < 10:
    # 반복할 코드
    print("Hello, world!")
    # 변화식
    i += 1
# → "Hello, world!" 10번 출력
📌 작동 방식
  • i = 0 설정 (초기식)
  • i < 10 인지 확인 (조건식)
  • 참 → "Hello, world!" 출력
  • i를 1 증가 (변화식: i += 1)
  • 조건식으로 돌아가 반복
  • i = 10 → 거짓 → 반복 종료
📌 초기식 · 조건식 · 변화식
  • 초기식: 반복 시작 전 변수 초기화 (예: i = 0)
  • 조건식: 반복 계속 여부 판단 (예: i < 10)
  • 변화식: 매 반복마다 변수를 변화시켜 종료 조건에 가까워짐 (예: i += 1)
⚠️ 변화식이 없으면 i가 계속 0 → 조건이 항상 참 → 무한 루프 발생!

🔹 range() 함수 — 완전 정리

›

range(시작, 끝, 변화량): 시작 이상 끝 미만 범위에서 변화량만큼 변화하는 수열

사용법생성되는 수열설명
range(5)0, 1, 2, 3, 4끝(5)만 지정. 시작=0, 변화량=1 자동
range(1, 6)1, 2, 3, 4, 5시작·끝 지정. 변화량=1 자동
range(0, 10, 1)0,1,2,…,9시작·끝·변화량 모두 지정
range(0, 10, 2)0, 2, 4, 6, 82씩 증가 (끝 10 미포함)
range(5, 0, -1)5, 4, 3, 2, 1변화량 음수 → 감소 (역순)
range(10, 0, -2)10, 8, 6, 4, 210에서 2씩 감소
✅ range() 안의 값은 1개(끝), 2개(시작·끝), 3개(시작·끝·변화량) 모두 가능. 끝점은 항상 포함되지 않습니다!

🔹 for 반복문 — 작동 원리

›

정해진 범위나 리스트의 값을 하나씩 꺼내며 반복합니다.

for i in range(1, 6):    # i = 1, 2, 3, 4, 5
    print(i, end=" ")     # 1 2 3 4 5

for c in "hello":         # c = h, e, l, l, o 순서로
    print(c, end="-")    # h-e-l-l-o-

fruits = ["사과", "바나나", "포도"]
for f in fruits:          # 리스트 원소 하나씩
    print(f)              # 사과 / 바나나 / 포도
키워드역할예시
break반복문 완전 종료특정 조건에서 루프 탈출
continue현재 반복 건너뛰고 다음으로특정 값 건너뛸 때
# break 예시: 3 찾으면 즉시 종료
for i in range(1, 6):
    if i == 3: break
    print(i, end=" ")  # 1 2

# continue 예시: 3 건너뛰기
for i in range(1, 6):
    if i == 3: continue
    print(i, end=" ")  # 1 2 4 5

🔹 함수 정의·호출·반환

›
def add(a, b):
    return a + b

result = add(3, 4)    # 7

# 기본값(default) 매개변수
def power(base, exp=2):
    return base ** exp

power(3)     # 9  (exp=2 기본값 사용)
power(3, 3)  # 27
매개변수 vs 인수

매개변수(parameter): 함수 정의 시
인수(argument): 함수 호출 시 전달

return 없으면?

return이 없거나 return만 있으면 None 반환

⚠️ 함수 안의 변수(지역 변수)는 함수 밖에서 사용할 수 없습니다!

🔹 전기의 기본 개념

›
개념단위기호설명
전압 (Voltage)볼트 (V)V전류를 흐르게 하는 힘
전류 (Current)암페어 (A)I전자의 흐름 (물의 흐름에 비유)
저항 (Resistance)옴 (Ω)R전류의 흐름을 방해하는 성질
옴의 법칙 (Ohm's Law)

V = I × R

  • 전류(I) = 전압(V) ÷ 저항(Ω)
  • 저항(R) = 전압(V) ÷ 전류(A)

예) 5V 전원, 100Ω 저항 → 전류 = 5 ÷ 100 = 0.05A = 50mA

🔹 직렬·병렬 연결

›
직렬 연결
  • 부품을 한 줄로 연결
  • 전류 동일: I 동일
  • 전압 분배: V = V₁+V₂
  • 저항 합산: R = R₁+R₂
병렬 연결
  • 부품을 여러 줄로 연결
  • 전압 동일: V 동일
  • 전류 분배: I = I₁+I₂
  • 저항 감소: 1/R = 1/R₁+1/R₂

🔹 피지컬 컴퓨팅 시스템

›

피지컬 컴퓨팅은 프로그래밍으로 물리적 세계(센서, 모터 등)와 상호작용하는 컴퓨팅입니다.

3단계 처리 흐름

입력(Input) → 처리(Process) → 출력(Output)

단계역할예시
입력물리적 정보를 전기 신호로 변환버튼, 온도·초음파·빛 센서
처리프로그램으로 신호를 처리라즈베리파이 피코, 아두이노
출력처리 결과를 물리적으로 표현LED, 모터, 스피커, 디스플레이

🔹 라즈베리파이 피코 & GPIO

›
  • 영국 라즈베리파이 재단이 개발한 마이크로컨트롤러 보드
  • 프로세서: RP2040 (듀얼코어 ARM Cortex-M0+)
  • MicroPython으로 프로그래밍 가능
  • GPIO: 디지털/아날로그 신호를 입출력하는 핀
from machine import Pin
import time
led = Pin(25, Pin.OUT)   # GPIO 25번을 출력으로 설정
while True:
    led.value(1)          # LED 켜기
    time.sleep(0.5)
    led.value(0)          # LED 끄기
    time.sleep(0.5)

인공지능(AI)은 인간의 지적 능력을 컴퓨터로 구현한 기술입니다.

AI 발전 3요소
  • 📊 빅데이터: 대량의 학습 데이터

인공지능 ⊃ 머신러닝 ⊃ 딥러닝

🔹 머신러닝(Machine Learning)

›

머신러닝은 사람이 직접 규칙을 설정하지 않고, 데이터로부터 패턴을 학습하여 예측·분류하는 기술입니다.

전통적 프로그래밍

데이터 + 규칙 → 결과

머신러닝

데이터 + 결과 → 규칙(모델)

용어설명
특성(Feature)입력 데이터의 속성 (예: 키, 몸무게)
레이블(Label)정답 데이터 (예: 성별)
모델(Model)학습을 통해 만들어진 예측 함수

🔹 지도·비지도·강화 학습

›
학습 유형특징예시
지도 학습정답(레이블)이 있는 데이터로 학습스팸 분류, 주택 가격 예측
비지도 학습정답 없이 데이터에서 패턴 발견군집화(Clustering)
강화 학습보상을 최대화하는 방향으로 학습알파고, 자율주행
지도학습의 두 가지 유형
분류 (Classification)

데이터를 범주로 예측
예: 스팸/정상 메일

회귀 (Regression)

연속 수치를 예측
예: 주택 가격 예측

🔹 모델 평가 & 과적합

›
데이터셋비율역할
훈련 데이터60~80%모델 학습
검증 데이터10~20%하이퍼파라미터 조정
테스트 데이터10~20%최종 성능 평가
과적합 (Overfitting)

훈련 데이터엔 잘 맞지만 새 데이터에 성능이 낮은 상태.
해결: 데이터 추가, 정규화

과소적합 (Underfitting)

훈련 데이터도 잘 못 맞춤. 모델이 너무 단순.
해결: 모델 복잡도 높임
