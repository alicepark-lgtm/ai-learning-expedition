🔹 추상화(Abstraction) 란?

›

추상화는 문제 해결에 불필요한 세부 사항을 제거하고 핵심적인 내용만 추려 표현하는 것입니다.

예를 들어 지하철 노선도는 실제 거리와 지형을 무시하고 역 이름과 환승 정보만 남긴 추상화입니다.

✅ 추상화 → 알고리즘 설계 → 프로그래밍 순서로 문제를 해결합니다.
절차 추상화

어떻게(How) 계산하는지 숨기고 무엇(What)을 하는지만 표현. 함수가 대표적 예시.

데이터 추상화

복잡한 데이터를 단순하게 표현. 리스트, 변수 등이 대표적 예시.

🔹 알고리즘(Algorithm) 이란?

›

알고리즘은 문제를 해결하기 위한 절차나 방법을 단계적으로 표현한 것입니다.

좋은 알고리즘의 조건 5가지:

  • 입력(Input): 0개 이상의 입력이 있어야 한다.
  • 출력(Output): 1개 이상의 출력이 있어야 한다.
  • 명확성(Definiteness): 각 단계가 명확하게 정의되어야 한다.
  • 유한성(Finiteness): 유한한 단계 후에 반드시 종료되어야 한다.
  • 효과성(Effectiveness): 각 단계가 실제로 수행 가능해야 한다.

›
방법설명특징

  • ▱ 평행사변형(입출력): 데이터 입출력

🔹 버블 정렬 (Bubble Sort)

›

인접한 두 원소를 비교하여 순서가 잘못된 경우 교환하는 방식. 가장 큰 값이 맨 뒤로 "버블처럼" 올라가는 것이 특징입니다.

  • n개의 데이터 → 최대 n-1회 반복
  • 1회전에서 가장 큰 값이 맨 뒤로 이동
  • 시간 복잡도: O(n²)
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):        # 전체 패스 횟수
        for j in range(n - 1 - i):  # 이미 정렬된 뒤는 제외
            if arr[j] > arr[j + 1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]  # 교환
    return arr

# 예시
data = [5, 3, 8, 1, 9, 2]
print(bubble_sort(data))  # [1, 2, 3, 5, 8, 9]
동작 예시: [3, 1, 2]

1회전: (3,1)교환→[1,3,2] → (3,2)교환→[1,2,3]
2회전: (1,2)비교→교환없음 → 완료

🔹 선택 정렬 (Selection Sort)

›

전체에서 가장 작은 값을 찾아 맨 앞으로 이동시키는 방식을 반복합니다.

  • n개의 데이터 → 최대 n-1회 반복
  • 매 회전마다 최솟값의 인덱스를 기억했다가 교환
  • 시간 복잡도: O(n²)
def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        min_idx = i           # 현재 위치를 최솟값 위치로 초기화
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j   # 더 작은 값 발견 시 인덱스 갱신
        arr[i], arr[min_idx] = arr[min_idx], arr[i]  # 교환
    return arr

data = [5, 3, 8, 1, 9, 2]
print(selection_sort(data))  # [1, 2, 3, 5, 8, 9]
동작 예시: [3, 1, 2]

1회전: 최솟값=1(인덱스1) → 3과 교환 → [1, 3, 2]
2회전: 최솟값=2(인덱스2) → 3과 교환 → [1, 2, 3]

🔹 순차 탐색 (Sequential Search)

›

데이터를 처음부터 끝까지 순서대로 하나씩 비교하며 찾는 방식입니다.

  • 정렬되지 않은 데이터도 탐색 가능
  • 최악의 경우: 마지막에 있거나 없는 경우 → n번 비교
  • 시간 복잡도: O(n)
def sequential_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i     # 찾은 위치(인덱스) 반환
    return -1             # 없으면 -1 반환

data = [4, 2, 7, 1, 9, 3]
print(sequential_search(data, 7))   # 2
print(sequential_search(data, 5))   # -1

🔹 이진 탐색 (Binary Search)

›

정렬된 데이터에서 중간값과 비교하며 탐색 범위를 절반씩 줄여가는 방식입니다.

  • 반드시 정렬된 데이터에서만 사용 가능
  • 매 단계마다 탐색 범위가 절반으로 감소
  • 시간 복잡도: O(log n) ← 순차탐색보다 훨씬 빠름
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2   # 중간 인덱스
        if arr[mid] == target:
            return mid               # 발견!
        elif arr[mid] < target:
            left = mid + 1           # 오른쪽 절반 탐색
        else:
            right = mid - 1          # 왼쪽 절반 탐색
    return -1

data = [1, 3, 5, 7, 9, 11, 13]
print(binary_search(data, 7))    # 3
print(binary_search(data, 6))    # -1
동작 예시: [1,3,5,7,9,11,13]에서 7 탐색

① left=0, right=6, mid=3 → arr[3]=7 == 7 → 발견! 인덱스 3 반환

⚠️ 이진 탐색은 반드시 정렬된 데이터에서만 사용 가능합니다!

🔹 전기의 기본 개념

›
개념단위기호설명
전압 (Voltage)볼트 (V)V전류를 흐르게 하는 힘. 수압에 비유.
전류 (Current)암페어 (A)I전자의 흐름. 물의 흐름에 비유.
저항 (Resistance)옴 (Ω)R전류의 흐름을 방해하는 성질.
옴의 법칙 (Ohm's Law)

V = I × R

  • 전압(V) = 전류(A) × 저항(Ω)
  • 전류(I) = 전압(V) ÷ 저항(Ω)
  • 저항(R) = 전압(V) ÷ 전류(A)
✅ 예시: 5V 전원, 저항 100Ω → 전류 = 5 ÷ 100 = 0.05A = 50mA

🔹 직렬·병렬 연결

›
직렬 연결
  • 부품을 한 줄로 연결
  • 전류가 같음: I 동일
  • 전압이 분배: V = V₁ + V₂
  • 저항이 합산: R = R₁ + R₂
병렬 연결
  • 부품을 여러 줄로 연결
  • 전압이 같음: V 동일
  • 전류가 분배: I = I₁ + I₂
  • 저항 감소: 1/R = 1/R₁ + 1/R₂

🔹 피지컬 컴퓨팅이란?

›

피지컬 컴퓨팅(Physical Computing)은 프로그래밍을 통해 물리적 세계(센서, 모터 등)와 상호작용하는 컴퓨팅입니다.

피지컬 컴퓨팅 시스템 3단계

입력(Input) → 처리(Process) → 출력(Output)

단계역할예시
입력물리적 환경 정보를 전기 신호로 변환버튼, 온도 센서, 초음파 센서, 빛 센서
처리입력 신호를 받아 프로그램으로 처리라즈베리파이 피코, 아두이노
출력처리 결과를 물리적으로 표현LED, 모터, 스피커, 디스플레이

🔹 라즈베리파이 피코 (Raspberry Pi Pico)

›
  • 영국 라즈베리파이 재단이 개발한 마이크로컨트롤러 보드
  • 프로세서: RP2040 (듀얼 코어 ARM Cortex-M0+)
  • MicroPython으로 프로그래밍 가능
  • GPIO(General Purpose Input/Output) 핀: 디지털/아날로그 신호 입출력
GPIO 핀 모드
모드설명예시
OUT (출력)마이크로컨트롤러 → 부품LED 켜기/끄기
IN (입력)부품 → 마이크로컨트롤러버튼 눌림 감지
from machine import Pin
import time

led = Pin(25, Pin.OUT)   # GPIO 25번을 출력으로 설정

while True:
    led.value(1)          # LED 켜기
    time.sleep(0.5)       # 0.5초 대기
    led.value(0)          # LED 끄기
    time.sleep(0.5)

🔹 디지털 신호 vs 아날로그 신호

›
디지털 신호
  • 0 또는 1 (HIGH/LOW)
  • 버튼, LED 제어
  • 정확한 값 표현
아날로그 신호
  • 연속적인 값 (0~3.3V)
  • 가변저항, 온도 센서
  • ADC(아날로그-디지털 변환)로 읽음

🔹 인공지능(AI)이란?

›

인공지능(Artificial Intelligence, AI)은 인간의 지적 능력을 컴퓨터로 구현한 기술입니다.

AI 발전 3요소
  • 📊 빅데이터: 대량의 학습 데이터
  • 💻 컴퓨팅 파워: GPU 등 고성능 하드웨어
  • 🧠 알고리즘: 딥러닝 등 개선된 학습 알고리즘
약한 AI (Narrow AI)

특정 작업만 수행. 현재 대부분의 AI.
예: 알파고, 음성인식, 이미지 인식

강한 AI (General AI)

인간처럼 모든 작업 수행. 아직 실현 안 됨.
예: SF 영화의 로봇

🔹 AI의 분류 체계

›

인공지능 ⊃ 머신러닝 ⊃ 딥러닝

개념설명
인공지능 (AI)인간 지능을 모방한 컴퓨터 기술 전반
머신러닝 (ML)데이터로부터 스스로 학습하는 AI의 한 분야
딥러닝 (DL)인공신경망을 깊게 쌓은 머신러닝의 한 분야

🔹 머신러닝(Machine Learning)이란?

›

머신러닝은 사람이 직접 규칙을 설정하지 않고, 데이터로부터 패턴을 학습하여 예측·분류하는 기술입니다.

전통적 프로그래밍

데이터 + 규칙 → 결과

머신러닝

데이터 + 결과 → 규칙(모델)

머신러닝 용어 정리
용어설명
데이터셋학습에 사용되는 데이터 집합
특성(Feature)입력 데이터의 속성 (예: 키, 몸무게)
레이블(Label)정답 데이터 (예: 성별)
모델(Model)학습을 통해 만들어진 예측 함수
학습(Training)모델이 데이터에서 패턴을 찾는 과정
예측(Prediction)학습된 모델로 새 데이터를 분류/예측

🔹 지도 학습 (Supervised Learning)

›

정답(레이블)이 있는 데이터로 학습합니다.

분류 (Classification)

데이터를 범주로 예측
예: 스팸 메일 분류, 손글씨 숫자 인식, 암 진단

회귀 (Regression)

데이터를 연속 수치로 예측
예: 주택 가격 예측, 기온 예측

대표 알고리즘: k-최근접 이웃(k-NN), 결정 트리, 선형 회귀, SVM

k-최근접 이웃 (k-NN) 알고리즘

새로운 데이터 주변의 가장 가까운 k개의 이웃을 찾아 다수결로 분류합니다.

  • k=1: 가장 가까운 1개 이웃의 클래스로 분류
  • k=3: 가장 가까운 3개 이웃 중 많은 클래스로 분류

🔹 비지도 학습 (Unsupervised Learning)

›

정답(레이블)이 없는 데이터에서 스스로 패턴을 찾습니다.

군집화 (Clustering)

유사한 데이터끼리 그룹(군집)으로 묶습니다.
예: 고객 분류, 문서 분류
대표 알고리즘: k-means

🔹 강화 학습 (Reinforcement Learning)

›

환경과의 상호작용을 통해 보상을 최대화하는 방향으로 학습합니다.

구성 요소설명예시
에이전트(Agent)학습하고 행동하는 주체게임 캐릭터
환경(Environment)에이전트가 상호작용하는 세계게임 맵
행동(Action)에이전트의 선택이동, 공격
보상(Reward)행동의 결과로 받는 점수+점수, -점수

예시: 알파고(바둑), 자율주행차, 게임 AI

🔹 데이터 분할: 훈련/검증/테스트

›
데이터셋비율(일반)역할
훈련 데이터60~80%모델 학습에 사용
검증 데이터10~20%하이퍼파라미터 조정
테스트 데이터10~20%최종 성능 평가
⚠️ 테스트 데이터는 학습에 절대 사용하지 않아야 합니다!

🔹 과적합 vs 과소적합

›
과적합 (Overfitting)
  • 훈련 데이터에 너무 딱 맞게 학습
  • 새 데이터 → 성능 낮음
  • 해결: 데이터 추가, 정규화
과소적합 (Underfitting)
  • 훈련 데이터도 잘 못 맞춤
  • 모델이 너무 단순
  • 해결: 모델 복잡도 높임

🔹 딥러닝과 인공신경망

›

인공신경망(ANN)은 인간의 뇌 신경세포(뉴런)를 모방한 구조입니다.

층역할
입력층데이터 입력
은닉층특성 추출 및 변환 (여러 층 = 딥러닝)
출력층최종 예측값 출력
✅ 딥러닝은 은닉층을 깊게(deep) 쌓아 복잡한 패턴을 학습합니다.
