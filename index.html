※ 기계학습이란?

■ 기계학습의 정의

기계학습(Machine Learning)은 사람의 학습 능력을 컴퓨터로 구현하는 인공지능 기술로서, 컴퓨터가 수많은 데이터로 학습 하여 모델을 만들고, 이 모델에 새로운 데이터를 적용하여 예측 과 분류 같은 지능적인 판단을 할 수 있다.

■ 일반 프로그래밍 vs 기계학습

🖥️ 일반 프로그래밍
데이터 + 규칙(사람이 작성)
↓
결과(출력)
🤖 기계학습
데이터 + 정답(레이블)
↓
규칙(모델)을 스스로 학습
💡 기계학습을 통해 만든 모델(Model)이란 데이터에서 발견한 패턴 과 규칙 을 수치화한 것으로, 새로운 데이터에 대한 예측이나 판단에 사용된다.
🗂️

■ 기계 학습의 유형

🏷️ — ( 지도학습 ) :
주어진 입력과 그것에 대한 정답 데이터로 학습한다. 학습을 위해 입력하는 속성을 특징 이라고 하고, 정답을 레이블 이라고 한다. 수많은 예시 데이터를 사용하여 데이터 간의 관계와 패턴을 인식하고 이해하도록 한다. 학습이 완료되면 레이블이 없는 새로운 데이터에 대해 정확한 예측 이나 분류 를 할 수 있다.
📌 사례: 스팸 메일 분류 · 날씨 예측 · 질병 진단
🔍 — ( 비지도학습 ) :
레이블 (정답) 없는 데이터를 스스로 학습하면서 데이터 안의 패턴 이나 구조 를 스스로 찾아내어 비슷한 것들을 그룹으로 묶거나 주요 특징을 추출하는 작업을 한다. 명확한 답이 없는 데이터를 다룰 때 유용하며, 스스로 학습하여 알려져 있지 않은 유용한 정보를 발견하는 데 도움이 된다.
※ 비슷한 것끼리 묶는 것을 군집화(클러스터링) 라고 한다.
📌 사례: 고객 세분화 마케팅 · 사진 자동 분류 · 도서 추천
🎮 — ( 강화학습 ) :
사람이 시행착오 를 겪으며 점점 나은 행동을 학습해 가는 방법과 비슷한 인공지능 학습 방법이다. 시행착오의 과정에서 어떤 행동에 대한 보상 이 주어지면 이러한 보상을 최대화 하는 방향으로 학습이 진행되어 점점 더 나은 행동을 하게 된다. 주어진 데이터나 환경에 대한 사전 지식 없이 스스로 학습하고 적응 하는 방법이다.
📌 사례: 알파고 · 자율주행 로봇 · 게임 캐릭터 학습
📝
